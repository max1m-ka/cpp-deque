# C++ Deque / Qt

Учебное приложение на C++ и Qt для практики работы со `std::deque` и итераторами.

## О проекте

Приложение предоставляет графический интерфейс для выполнения основных операций над `std::deque<std::string>`.

Реализованы операции:

- добавление и удаление элементов с начала и конца;
- вставка и удаление элементов;
- изменение размера контейнера;
- поиск и подсчёт элементов;
- поиск минимума и максимума;
- сортировка и проверка сортировки;
- удаление дубликатов;
- разворот и перемешивание элементов;
- работа с `begin()` / `end()`;
- поиск через `lower_bound()` и `upper_bound()`.

## Технологии

- C++
- Qt Widgets
- `std::deque`
- итераторы STL
- алгоритмы STL
- `std::mt19937`

## Структура

- `main.cpp` — точка входа приложения;
- `mainwindow.*` — графический интерфейс и обработчики действий пользователя;
- `model.h` — модель данных на основе `std::deque<std::string>`.

## Цель проекта

Проект выполнен в рамках обучения C++ и предназначен для закрепления навыков работы с контейнерами STL, итераторами и алгоритмами, а также для практики разработки интерфейсов на Qt.
